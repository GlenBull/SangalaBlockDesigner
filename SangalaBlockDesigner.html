Sangala Block Designer

Sangala Block Designer is a block design tool. The outline of a figure designed in Sangala Studio is brought in as a frame, and the designer builds that figure from real LEGO bricks, choosing every part and placing it by hand. Each brick carries the design number it is ordered by, so a finished design is also its own parts list.

The icon representing Sangala Block Designer in its logo and the desktop launcher is a crowned crane built from bricks.
